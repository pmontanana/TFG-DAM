## 📦 Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/pmontanana/TFG-DAM.git
   cd TFG-DAM
   ```

2. Instala las dependencias necesarias:
  ```bash
  flutter pub get
  ```

---

## 🚦 Uso


```bash
cd TFG-DAM
dart run main.dart
```
